:

This project focuses on recurrent neural networks (RNNs). You will implement a RNN that uses the gated recurrent unit (GRU) recurrent layer from deep learning to generate synthetic novel movie reviews after being trained on the IMDb dataset.

This project builds on and further develops the notion that neural networks process information over time through recurrent connections and medium-term memory states that was introduced with predictive coding networks.


Objectives

  • Implement a Gated Recurrent Unit (GRU), a modern recurrent neural network layer.
  • Develop a thorough understanding the mechanisms in a neural networks can be used to generate novel text sequences.
  • Gain more experience working with recurrent connections and medium-term memory states.
  • Gain experience working with a character-level NLP model.

Character RNN Text Generation

A from-scratch GRU RNN implementation that turns raw text into character sequences, trains recurrent state, masks padding, and samples new text from learned probabilities.

Pipeline

1. Clean textRemove HTML and non-printing characters from review text.
2. Encode charsAdd start, end, and pad tokens, then map characters to integer ids.
3. Train recurrent stateUse embeddings, GRU state, and softmax output over the vocabulary.
4. Sample textFeed each generated character back into the model one time step at a time.

The interesting part is not perfect prose. It is that a small recurrent model learns enough local structure to continue a story, and its mistakes reveal how probabilistic sampling compounds over time.
